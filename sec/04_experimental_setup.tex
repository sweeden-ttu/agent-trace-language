\section{Experimental Setup}
\label{sec:expsetup}

\subsection{Benchmark}

We instantiate the architecture on the \textsc{Spaceship Titanic}
task from \textsc{MLE-bench}.  The task is a binary-classification
competition hosted on Kaggle with 2330 active teams.  It requires
non-trivial feature engineering (cabin decomposition, group-aware
k-fold splitting) and has a clearly defined submission validity
criterion.

\subsection{Hardware and reproducibility}

All runs were executed on a single macOS laptop
(gemini-2.5-pro/gemini-2.5-flash-lite via the google-genai client),
with heavier ablation runs supported by the Texas Tech HPCC.
Complete reproducibility artefacts---start-language CSV, enumerated
trace CSV, and submission notebooks---are released at
\url{https://www.kaggle.com/scottweeden/competitions}.

\subsection{Start language}

The start language $L_0 = L(\texttt{trace\_language\_original.csv})$
has alphabet $\Sigma_0$ of approximately 90 operation symbols across
twelve sub-agent columns.  $L_0$ was constructed from the
open-source \textsc{MLE-bench} stubs and Kaggle CLI documentation; no
competition-specific knowledge entered it.  Symbols pertaining to
the \textsc{Spaceship Titanic} feature space appear only after the
recursive enumeration materialises them under the verifier's
pressure.

\subsection{Verifier keyword set}

The verifier $\mathcal{V}$ is the Aho--Corasick DFA over keyword set
$K$ obtained from (i) the \texttt{tools\_index} column of $L_0$,
(ii) the \texttt{unit\_test\_runner} column of $L_0$, and (iii)
column-name/dtype keywords from the task schema.  $|K|$ is
approximately 54 keywords; $\|K\| \approx 1{,}200$ characters; the
DFA has on the order of $10^3$ states.

\subsection{Pre-registered probes}

We pre-register four probes:

\paragraph{P1 (Type-3 envelope of $\mathcal{V}$).}
The verifier's membership decision runs in linear time per prefix.
Refutation: any super-linear verifier timing.

\paragraph{P2 (trace growth).}
The realised trace strictly exceeds every start-language column in
length.  Refutation: the realised trace is no longer than the seed
columns.

\paragraph{P3 (emergent agent).}
The realised trace contains a thirteenth column
(\texttt{kaggle\_trainer}) absent from $\Sigma_0$.
Refutation: no new column appears.

\paragraph{P4 (leaderboard placement).}
The validated trace yields public leaderboard placement at or above
$777/2330$ (top tertile).  Refutation: placement strictly worse than
$777/2330$.

\subsection{Controlled validation suite}

To isolate the verifier's causal effect we complement the Kaggle run
with a local sandbox (\path{src/run\_experiments.py},
\path{src/ablation.py}) executing real ML steps under injected
faults.  The sandbox compares generator-only
($\mathcal{G}$), $\mathcal{G}\,\Vert\,\mathcal{V}_{\mathrm{DFA}}$,
and $\mathcal{G}\,\Vert\,\mathcal{V}_{\mathrm{LLM}}$ bindings.
Aggregated outcomes are reported in
Section~\ref{sec:results}.  The sandbox does not replace the Kaggle
evidence; it supplies the controlled contrast the leaderboard alone
cannot.
