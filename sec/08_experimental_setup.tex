\section{Experimental Setup}
\label{sec:expsetup}

\subsection{Benchmark}

We instantiate the architecture on the \textsc{Spaceship Titanic}
task drawn from the publicly hosted \textsc{MLE-bench} suite
(\texttt{github.com/openai/mle-bench}).
\textsc{Spaceship Titanic} is a binary-classification competition
in which the agent must predict, for each test passenger, whether
they were transported to an alternate dimension during a fictional
inter-stellar collision.  The competition is hosted on Kaggle as a
``Getting Started'' competition, has 2330 active teams as of the
date of submission, and uses public-leaderboard accuracy as its
ranking metric.

The task is selected for three reasons: it requires non-trivial
feature engineering (compound \texttt{Cabin} field decomposition,
group-aware k-fold splitting, missingness-indicator generation);
it has a clearly defined submission validity criterion (column
names, row count, no missing predictions); and its leaderboard is
sufficiently dense that a $2$--$5\%$ placement improvement
constitutes a reproducible, statistically meaningful signal.

\subsection{Hardware and software environment}

\begin{itemize}
\item Hardware: a single laptop (the author's macOS development
machine).  CPU and RAM bounds are recorded in the run log; both
are finite and the realised computation is therefore an LBA in
the formal sense of Section~\ref{sec:preliminaries}.
\item Operating system: macOS, with the Kaggle CLI version locked
in the run-time configuration.
\item LLM backbone: Google Gemini, accessed through the
\texttt{google-genai} client.  Two model strings appear in the
realised trace: \texttt{gemini-2.5-pro} for open-ended deliberation
steps; \texttt{gemini-2.5-flash} and
\texttt{gemini-2.5-flash-lite} for finite-state housekeeping and
verification-adjacent steps.
\item Embedding backbone: \texttt{text-embedding-004} for the
research-agent vector store and the tools-index keyword
embedding.
\end{itemize}

The deliberate restriction of the backbone to a single hosted LLM
family is methodological: the goal is to minimise the
architectural surface area while exhibiting the trace-language
phenomenon.  We report no comparison across backbone families.

\subsection{Start language}

The start language $L_0 = L(\texttt{trace\_language\_original.csv})$
is the publicly attached artefact in
\path{data/trace_language_original.csv}.  Its alphabet
$\Sigma_0$ is the set of operation symbols read off the file's
twelve columns.  $|\Sigma_0|$ is approximately 90, after
deduplication of recurring symbols across columns.

The start language was constructed by hand from the open-source
\textsc{MLE-bench} agent stubs and from the standard Kaggle CLI
documentation.  No competition-specific knowledge entered
$L_0$: the start language is task-agnostic.  In particular,
$L_0$ contains no symbol pertaining to the \textsc{Spaceship
Titanic} feature space (no \texttt{Cabin}, no \texttt{HomePlanet},
no \texttt{CryoSleep}); these symbols enter only after the
recursive enumeration of Algorithm~\ref{alg:enum} has materialised
them under the verifier's pressure.

\subsection{Verifier keyword set}

The verifier $\mathcal{V}$ is the Aho--Corasick DFA $M_K$
constructed from the keyword set $K$ obtained by:
\begin{enumerate}
\item Reading the \texttt{tools\_index} column of $L_0$ and
including each operation symbol (e.g.,
\texttt{score\_against\_index(cosine)}).
\item Reading the \texttt{unit\_test\_runner} column of $L_0$
and including each \texttt{test\_*} symbol (e.g.,
\texttt{test\_submission\_validity},
\texttt{test\_column\_names\_submission}).
\item Adjoining the column-name and dtype keywords mechanically
extracted from the
\textsc{Spaceship Titanic} \texttt{train.csv} schema:
\textsf{PassengerId}, \textsf{HomePlanet}, \textsf{CryoSleep},
\textsf{Cabin}, \textsf{Destination}, \textsf{Age},
\textsf{VIP}, \textsf{RoomService}, \textsf{FoodCourt},
\textsf{ShoppingMall}, \textsf{Spa}, \textsf{VRDeck},
\textsf{Name}, \textsf{Transported}.
\end{enumerate}
The full $K$ is enumerated in Appendix~A.  $|K|$ is approximately
54 keywords; $\|K\|$ is approximately 1,200 characters.  The
Aho--Corasick DFA has on the order of $10^3$ states.

\subsection{Probes and predictions}

To preserve falsifiability, we pre-register four probes against
the architecture before running the binding.

\paragraph{P1 (Type-3 envelope of $\mathcal{V}$).}
The verifier's trace language is regular.  The empirical
prediction is that the membership decision per candidate prefix
runs in time linear in prefix length, with a flat constant in
prefix length.  Refutation: any super-linear timing on
$\mathcal{V}$'s side.

\paragraph{P2 (trace growth beyond the seed artifact).}
The Goal-Driven agent emits at least one accepted trace whose length
strictly exceeds every corresponding start-language column.  This is
an empirical trace-growth prediction, not a language-class separation
claim.  Refutation: the realised trace is no longer than the
start-language columns.

\paragraph{P3 (Emergent thirteenth agent).}
The realised trace contains operation symbols that are not in
$\Sigma_0$, and these symbols cluster into a thirteenth column
(\texttt{kaggle\_trainer}) absent from
\texttt{trace\_language\_original.csv}.  Refutation: no new
column appears, or the new symbols do not cluster into a coherent
sub-agent.

\paragraph{P4 (Leaderboard placement).}
The validated trace, executed end-to-end, yields a public
leaderboard placement at or above the top tertile of submissions
(i.e., rank $\le 0.333\cdot 2330 \approx 777$).  Refutation: a
placement strictly worse than $777/2330$.

These four probes are pre-registered in the sense that their
predictions are stated before the binding is run.  We report
their outcomes in Section~\ref{sec:results}.

\subsection{Reproducibility artefacts}

The following artefacts are released with this paper:
\begin{itemize}
\item \path{data/trace_language_original.csv} --- the start
language $L_0$ with twelve sub-agent columns.
\item \path{data/trace_language_kaggle.csv} --- the recursively
enumerated trace $L_1$ with thirteen sub-agent columns.
\item This paper's \LaTeX{} source, including the
\path{refs.bib} bibliography of Turing-laureate works, in
\path{~/agentic_chomsky_formalization/}.
\end{itemize}

The Kaggle submission CSV itself is not released, on the
deliberate principle that its release would contaminate the
benchmark for future researchers; the leaderboard placement is
reported as a single validated rank-out-of-N number.
