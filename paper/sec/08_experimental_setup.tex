\section{Experimental Setup}
\label{sec:expsetup}

\subsection{Benchmark tasks}

We instantiate the architecture on two tasks.

\paragraph{NeuroGolf ONNX ARC-AGI.}
The primary empirical domain is the \textsc{NeuroGolf ONNX}
competition (Kaggle, 2026), in which the agent must synthesize,
verify, and optimize ONNX computational graphs representing cellular
automata solvers for the ARC-AGI reasoning benchmark.  This is the
primary domain because its correctness criterion is formally
verifiable by the pipeline DFA: a graph either passes all
verification steps or it does not.  The trace CSV and verifier code
are fully open-source.

\paragraph{Spaceship Titanic (MLE-bench).}
As a secondary validation, we instantiate the same architecture on
the \textsc{Spaceship Titanic} binary classification task from the
\textsc{MLE-bench} suite
(\texttt{github.com/openai/mle-bench}), which provides a
fixed public leaderboard against which placement is reproducibly
measurable.  We report a single public-leaderboard placement,
acknowledging that this task uses a keyword-based verifier rather
than the pipeline DFA.

\subsection{Start language $L_0$}

The start language $L_0$ is formally defined as the language of the
seed CSV:
\[
L_0 \;=\; L\bigl(\texttt{experiment\_6/trace\_language\_start.csv}\bigr).
\]
Its alphabet $\Sigma_0$ consists of the \textbf{9~operation
symbols} appearing in the \texttt{op} column of that file:
\textsf{ANALYZE\_TASK}, \textsf{BLEND\_BUNDLE}, \textsf{BUILD\_ONNX},
\textsf{DISCOVER\_BUNDLE}, \textsf{LOAD\_FLOOR}, \textsf{SAVE\_MODEL},
\textsf{SUBMIT}, \textsf{VERIFY\_TEST}, \textsf{VERIFY\_TRAIN}.
The file records \textbf{7~sub-agents}:
\texttt{scanner}, \texttt{floor\_loader}, \texttt{analyzer},
\texttt{builder}, \texttt{verifier}, \texttt{blender}, \texttt{orch}.
Each sub-agent's alphabet is the restriction of $\Sigma_0$ to the
operations appearing in its column.

The start language was assembled by hand from baseline pipeline
stubs describing the ONNX graph-building workflow.  No
task-specific graph topologies or ARC-task identifiers entered
$L_0$: the seed alphabet is task-agnostic.

\subsection{Pre-registered empirical probes}

To preserve falsifiability, we pre-register four probes.

\paragraph{P1 (Linear verifier time).}
The verifier's membership decision is $O(|\tau|)$ in trace length
and $O(1)$ per operation symbol, because $\mathcal{V}$ is a DFA.
We test this empirically by instrumenting
\texttt{verify\_trace()} with microsecond-precision wall-clock
timing over $10^4$ independent calls on the 39-step realised trace.
Refutation criterion: a statistically significant super-linear
relationship between trace length and per-step time.

\paragraph{P2 (Alphabet expansion under enumeration).}
The recursive enumeration of Algorithm~\ref{alg:enum} will produce
a trace whose operation alphabet $\Sigma_1$ strictly extends the
seed $\Sigma_0$, with at least one operation symbol that does not
appear in the start language.  Refutation criterion: $\Sigma_1
\subseteq \Sigma_0$ (no new symbols generated).

\paragraph{P3 (Emergent agent roles).}
The realised trace will exhibit operation sequences that cluster
into functionally distinct sub-agent roles not present in $L_0$.
Specifically, the \texttt{miner}, \texttt{optimizer},
\texttt{grader}, and \texttt{packager} roles are absent from the
7-agent start language; we predict their emergence under the
verifier's pressure.  Refutation criterion: no new agent column
appears in the realised CSV.

\paragraph{P4 (Competitive task performance).}
The verified pipeline, executed end-to-end, will achieve a public
leaderboard score in the top tertile of its competition.
Refutation criterion: a score or placement in the bottom two-thirds.

These probes are stated prior to reporting results in
Section~\ref{sec:results}.
